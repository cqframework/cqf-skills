# FHIR Shorthand 3.0.0 Specification

The FSH language reference, split into one file per section. Generated by `scripts/build-spec.py` from [HL7/fhir-shorthand](https://github.com/HL7/fhir-shorthand/tree/b1c724f1d6f7d206ad714ccc0d82ce33110ce0c9) (CC0-1.0); the published specification is at <https://hl7.org/fhir/uv/shorthand/>.

Markers carried over from the published spec:

- `[TU]` and **[Trial Use]** blocks mark trial-use features. Everything else in the reference is normative, except examples.
- In syntax expressions, `«...»` marks an OPTIONAL part (orange text in the published spec), `{...}` a value to substitute, and `<...>` an element path of the given type.
